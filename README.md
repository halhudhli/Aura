# Aura

مشغّل فيديو للأندرويد بلا إعلانات ولا تتبّع.

- مكتبة لفيديوهات الجهاز: المجلدات، كل الفيديوهات، الأحدث، المفضلة، سجل المشاهدة، والبحث.
- يشغّل الصيغ الشائعة كلها (MKV، MP4، AVI…) عبر مكتبة mpv.
- إيماءات: السحب للتقديم والترجيع، السطوع، الصوت، ضغطتان للقفز، وضغط مطوّل للتسريع.
- الترجمة: المسارات المدمجة، وملف خارجي مع اكتشاف الترميز العربي، وتعديل الحجم والتوقيت.
- البحث عن ترجمة عبر SubSense وOpenSubtitles PRO من داخل المشغّل، واختيار اللغة والمصدر والنسخة، ثم تحميلها وتشغيلها مباشرةً.
- المتابعة من آخر موضع، وصورة داخل صورة، وفتح روابط الفيديو.
- خمسة أشكال تُختار من الإعدادات.

يُبنى الملف تلقائياً عبر GitHub Actions مع كل تعديل، ويُنشر في صفحة الإصدارات.

## البحث عن الترجمات

من داخل الفيديو: **الترجمة ← البحث عن ترجمة عبر الإنترنت**. يُجهّز اسم الفيديو للبحث ويمكن تعديله، والعربية هي اللغة الافتراضية. اختر الفيلم أو المسلسل المطابق من النتائج، ثم اختر نسخة الترجمة لتحميلها وتشغيلها مباشرةً. للمسلسلات يُستخرج الموسم والحلقة من اسم الملف عند توفرهما، ويمكن تعديلهما يدويًا.

تُجمع نتائج SubSense وOpenSubtitles PRO، مع إظهار مصدر كل ترجمة وإمكانية تصفية النتائج بالمصدر. يستطيع SubSense توفير SubDL وSubSource عند تفعيلهما في إعداد رابط الإضافة. تعطل مصدر لا يلغي النتائج من المصدر الآخر. تدعم الملفات المحمّلة SRT وVTT وASS، والملفات المضغوطة بـGZIP.

البحث لا يبدأ إلا عند الضغط على «بحث»: يُرسل الاسم إلى Cinemeta لاختيار العمل الصحيح، ثم يُرسل معرّف العمل واسم الفيديو إلى الإضافات. لا يُرفع الفيديو نفسه. تُحفظ الترجمات في ذاكرة التطبيق المؤقتة؛ إعادة اختيار النتيجة نفسها لا تُنزّل ملفها مجددًا ما دام محفوظًا. يظل اختيار ملف ترجمة من الجهاز متاحًا أيضًا.

### تفعيل الخدمة عند البناء

1. افتح [SubSense](https://subsense.nepiraw.com/)، واختر العربية واللغات الأخرى المطلوبة. أضف مفتاحي SubDL وSubSource في إعداد الإضافة لتفعيلهما، ثم استخدم **Copy Manifest URL**.
2. افتح إعداد OpenSubtitles PRO وانسخ رابط manifest الخاص به أيضًا.
3. في مستودع GitHub افتح **Settings → Secrets and variables → Actions → New repository secret** وأضف:

| اسم السر | القيمة |
|---|---|
| `SUBSENSE_API_KEY` | رابط SubSense الكامل المنتهي بـ`/manifest.json` |
| `OPENSUBTITLESPRO_API_KEY` | رابط OpenSubtitles PRO الكامل المنتهي بـ`/manifest.json` |

هذه الأسماء متوافقة مع إعداد المستودع؛ القيم روابط إعداد كاملة، وليست مفاتيح API خامًا. تُقبل روابط `https://` و`stremio://`. يكفي وجود أحد المصدرين لتفعيل البحث. يجب تفعيل اللغة المطلوبة في إعداد رابط الإضافة نفسه؛ تغيير اللغة داخل Aura يصفّي النتائج ولا يغيّر إعداد الإضافة المشفّر.

بعد إضافة السرّين أعد البناء من **Actions → Build Aura APK → Run workflow**، واختر فرع التغييرات عند تجربة طلب الدمج. إضافة السر وحدها لا تغيّر APK سبق بناؤه.

للبناء محليًا، عيّن متغيرَي البيئة بالاسمين نفسيهما قبل تشغيل Gradle. الروابط تُقرأ أثناء البناء ولا تُحفظ في المصدر؛ لكنها تُضمّن في APK للاتصال المباشر بالإضافات، لذلك تُعامل النسخة الموزعة باعتبارها تحتوي إعداد الإضافات. تُبنى النسخة بدون روابط أيضًا، لكنها توضّح أن البحث غير مفعّل، مع استمرار تشغيل الفيديو والترجمات المحلية.

يعتمد الربط على [بروتوكول إضافات Stremio](https://stremio.github.io/stremio-addon-sdk/protocol.html) ولا يحتاج تثبيت تطبيق Stremio على الجهاز.

### التحقق ونسخ التجربة

يشغّل GitHub Actions اختبارات خدمة الترجمة وAndroid Lint، ويبني APK. لطلبات الدمج وفروع التجربة، تُرفق النسخة وتقارير الاختبارات في Artifacts؛ نشر إصدار تلقائي يحدث فقط من فرع `main`.

عند تشغيل البناء يدويًا، يمكن تفعيل `verify_subtitles_api` لاختبار البحث الحقيقي عن عمل وترجماته بالإضافات المضافة، بدون تنزيل ملف. يبقى هذا الفحص اختياريًا حتى لا تعتمد الاختبارات العادية على توفر الخدمات الخارجية.

```sh
./gradlew :app:testDebugUnitTest :app:lintDebug :app:assembleDebug
```
