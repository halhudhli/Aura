# Aura

مشغّل فيديو للأندرويد بلا إعلانات ولا تتبّع.

- مكتبة لفيديوهات الجهاز: المجلدات، كل الفيديوهات، الأحدث، المفضلة، سجل المشاهدة، والبحث.
- يشغّل الصيغ الشائعة كلها (MKV، MP4، AVI…) عبر مكتبة mpv.
- إيماءات: السحب للتقديم والترجيع، السطوع، الصوت، ضغطتان للقفز، وضغط مطوّل للتسريع.
- الترجمة: المسارات المدمجة، وملف خارجي مع اكتشاف الترميز العربي، وتعديل الحجم والتوقيت.
- البحث عن ترجمة عبر OpenSubtitles من داخل المشغّل، واختيار اللغة والنسخة، ثم تحميلها وتشغيلها مباشرةً.
- المتابعة من آخر موضع، وصورة داخل صورة، وفتح روابط الفيديو.
- خمسة أشكال تُختار من الإعدادات.

يُبنى الملف تلقائياً عبر GitHub Actions مع كل تعديل، ويُنشر في صفحة الإصدارات.

## البحث عن الترجمات

من داخل الفيديو: **الترجمة ← البحث عن ترجمة عبر الإنترنت**. يُجهّز اسم الفيديو للبحث ويمكن تعديله، والعربية هي اللغة الافتراضية. اختر نتيجة لتحميلها وتشغيلها؛ يظل اختيار ملف ترجمة من الجهاز متاحًا أيضًا.

البحث لا يبدأ إلا عند الضغط على «بحث»، ويرسل اسم البحث واللغة إلى OpenSubtitles، ولا يرفع الفيديو نفسه. تُحفظ الترجمة في ذاكرة التطبيق المؤقتة؛ اختيار النسخة نفسها مجددًا لا يستهلك تحميلًا آخر ما دام الملف محفوظًا. تفرض الخدمة حدودًا يومية للتحميل، وتظهر رسالة عند بلوغها.

### تفعيل الخدمة عند البناء

1. أنشئ حسابًا على [OpenSubtitles](https://www.opensubtitles.com)، ثم سجّل Aura كتطبيق في [API Consumers](https://www.opensubtitles.com/consumers) للحصول على مفتاح API.
2. في مستودع GitHub افتح **Settings → Secrets and variables → Actions → New repository secret** وأضف المفتاح باسم `OPENSUBTITLES_API_KEY`.
3. أعد تشغيل بناء التطبيق من **Actions → Build Aura APK → Run workflow**. إضافة السر وحدها لا تغيّر APK سبق بناؤه.

للبناء محليًا، عيّن متغير البيئة `OPENSUBTITLES_API_KEY` قبل تشغيل Gradle. المفتاح يُقرأ أثناء البناء ولا يُحفظ في ملفات المصدر؛ لكنه يُضمّن في APK لأن التطبيق يتصل بالخدمة مباشرةً. لا تضع بيانات دخولك الشخصية في الكود. تُبنى النسخة بدون مفتاح أيضًا، لكنها توضّح أن البحث غير مفعّل، مع استمرار تشغيل الفيديو والترجمات المحلية.

توثيق الخدمة: [OpenSubtitles API](https://opensubtitles.tawk.help/article/getting-started).

### التحقق ونسخ التجربة

يشغّل GitHub Actions اختبارات خدمة الترجمة وAndroid Lint، ويبني APK. لطلبات الدمج وفروع التجربة، تُرفق النسخة وتقارير الاختبارات في Artifacts؛ نشر إصدار تلقائي يحدث فقط من فرع `main`.

```sh
./gradlew :app:testDebugUnitTest :app:lintDebug :app:assembleDebug
```
